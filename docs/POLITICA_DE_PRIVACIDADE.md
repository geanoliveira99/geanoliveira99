## 4. Armazenamento e Retenção de Dados

### localStorage (Navegador)
- **Local**: Apenas no seu navegador, nenhum servidor
- **Conteúdo**: Preferência de tema (dark/light)
- **Duração**: Permanece até você limpar cache/cookies do navegador
- **Segurança**: Criptografia nativa do navegador

### Comunicações (Email, WhatsApp)
- **Responsável**: Gmail, WhatsApp (serviços de terceiros)
- **Duração**: Conforme políticas desses serviços
- **Acesso**: Apenas pelo provedor da mensagem

### Arquivos em Utilitários
- **Processamento**: Apenas enquanto você está usando
- **Armazenamento**: Não salvamos em servidor
- **Exclusão**: Apagados automaticamente após a sessão

## 6. Segurança

Implementamos as seguintes medidas de segurança:

✅ **HTTPS**: Conexão criptografada entre você e nosso servidor  
✅ **localStorage Seguro**: Dados armazenados localmente, nunca em servidor  
✅ **Sem Análise Invasiva**: Não rastreamos seu comportamento  
✅ **Validação de Entrada**: Protegemos contra injeções de código  
✅ **Sem Dados Sensíveis**: Não coletamos CPF, cartão, senhas, etc.
