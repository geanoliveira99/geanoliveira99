## Importante: Responsabilidades das Ferramentas Externas

### 🎨 Remover Fundo de Imagens (@imgly)

**ESTA FERRAMENTA USA UM SERVIÇO EXTERNO QUE NÃO É RESPONSABILIDADE DESTE SITE.**

#### O que acontece:
1. ✅ Você seleciona uma imagem
2. 🔗 A imagem é **enviada para os servidores da @imgly**
3. 🤖 A @imgly processa usando IA
4. ⬇️ Resultado é retornado para você
5. 🗑️ Imagem é descartada (não armazenada permanentemente)

#### Quem é responsável:
- ✅ **Nós somos responsáveis** por: Fornecer o acesso à ferramenta, validação básica
- ❌ **Nós NÃO somos responsáveis** por:
  - Qualidade da remoção de fundo
  - Velocidade de processamento
  - Disponibilidade do serviço
  - Segurança dos dados (isso é responsabilidade da @imgly)
  - Perdas ou vazamentos de imagens

#### Responsabilidade da @imgly:
- 🔒 Segurança das imagens processadas
- ⚡ Qualidade da IA
- 📊 Armazenamento (ou não) das imagens
- 🔑 Conformidade com políticas de privacidade deles

**Leia a política deles**: https://www.imgly.io/privacy

## Como Usar com Segurança

### ⚠️ Antes de Usar "Remover Fundo":
1. **Faça backup** da imagem original
2. **Verifique**: A imagem não tem dados sensíveis
3. **Teste**: Com uma imagem pequena primeiro
4. **Leia**: Política de privacidade da @imgly
5. **Use**: Apenas se aceitar enviar para servidor deles

### ✅ Imagens Seguras para Enviar:
- Fotos pessoais
- Screenshots públicos
- Imagens de produtos
- Ilustrações

### ❌ Não Envie:
- Documentos com dados pessoais
- Screenshots com senhas
- Informações confidenciais
- Dados de clientes
